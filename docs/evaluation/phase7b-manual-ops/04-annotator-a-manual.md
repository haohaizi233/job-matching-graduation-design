# 04 · 标注员 A 独立操作手册

操作者：标注员 A（**真实人类**）。核心纪律：**独立标注**——A/B 不得交流个案，
不得查看对方标注，不得查看任何模型输出/排序结果。

## 前置

- [ ] 已阅读 `configs/phase7-preregistered-protocol-v1.json` 的标注口径
      （相关性增益 **{0,1,2}** 三级；主指标 NDCG@10；不可判定按协议
      `min_group_size_for_ranking` / `unjudgeable_handling` 口径记录）；
- [ ] 已完成 `scripts/phase7/annotation_drill.py` 合成演练（工具熟练度），
      **演练数据不计入真实覆盖率**；
- [ ] 本人与提供者无直接利害关系需回避的，先声明。

## 标注流程（每个查询组 = 1 份简历 × N 个候选岗位）

1. 领取批次任务：`data/private/annotation/tasks/A/BATCH-###.jsonl`（只读任务包）；
2. 打开任务包中的简历（编号 `R-###`）与候选岗位文本（编号 `J-###`）；
3. 依据协议口径对**每一对**（R, J）给出相关性等级 0 / 1 / 2：
   - **2**：高度匹配（核心技能/方向/经验年限整体吻合）；
   - **1**：部分匹配（部分条件吻合，存在明显短板）；
   - **0**：不匹配（方向或核心要求明显不符）；
   - 无法判定：记 `unjudgeable` 并写明理由（简历信息缺失/岗位描述含糊）；
4. 可加简短理由（≤50 字），**不得**粘贴简历原文到标注文件；
5. 每条标注独立判断，**不得**与简历提供者核对答案；
6. 结果写入 `data/private/annotation/results/A/BATCH-###.jsonl`：
   `pair_id / label / reason? / annotated_at / annotator_id`；
7. 完成后运行 `py -3.13 scripts/phase7/audit_real_data_status.py` 核对
   双人覆盖率（只看计数）。

## 禁止事项

- 与标注员 B 讨论具体配对（分歧由仲裁员处理）；
- 查看/询问任何模型排序、分数、推荐结果（防泄漏）；
- 代标、批量复制标签、让他人代签标注；
- 在标注文件中记录姓名、联系方式或简历正文。
