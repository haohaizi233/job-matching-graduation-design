# 02 · 知情同意操作步骤

操作者：组织者（真人）+ 简历提供者（真人）。**AI 不得代签或伪造签署时间。**

## 步骤

1. **当面/线上会议说明**：逐条讲解 `01-recruitment.md` 的用途、范围、存储、
   风险、权利；留出提问时间；
2. **交付同意书**：纸质或电子版（模板见 `data/private/consent/templates/`，
   不入库）；同意书必须包含：
   - 研究题目与单位（毕业设计、学校、作者姓名）；
   - 数据范围与用途（仅本研究评测）；
   - 存储位置与保密措施、保存期限（建议：答辩结束后 N 个月内删除，N 由作者确定）；
   - 撤回方式与联系人；
   - 是否同意匿名引用简历片段（默认不同意，需单独勾选）；
3. **本人签署**：提供者亲笔/电子签名 + **本人填写**签署日期；
   组织者只核对完整性，**不得代填日期或勾选同意**；
4. **编号登记**：签署后立即分配编号（`R-001` 起），将「编号 → 签署时间 →
   同意书文件哈希（sha256）」登记到 `data/private/consent/consent-log.jsonl`；
   同意书扫描件存 `data/private/consent/evidence/`（不入库）；
5. **校验**：运行 `py -3.13 scripts/phase7/audit_real_data_status.py`，
   确认 `consent` 计数增加；状态报告**只显示计数**，不显示签署人信息。

## 一致性要求

- 同意书哈希登记后不得修改文件（修改即哈希漂移，视为同意失效需重签）；
- 签署时间不得晚于数据导入时间；
- 未签署/签署不全的简历**不得**导入（`intake_accepted` 不计数）。

## 禁止事项

- 自动勾选同意、批量「代签」、补签历史日期；
- 把同意书扫描件传到公开仓库/网盘分享链接/聊天群。
