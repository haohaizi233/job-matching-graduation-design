## 规则

- 计数必须与 `py -3.13 scripts/phase7/audit_real_data_status.py` 输出一致，
  不一致当日报异常并查原因；
- 模板中不得出现姓名、手机号、邮箱、简历正文；
- 连续 3 日计数停滞需在「异常与风险」写明原因（招募/标注产能/撤回）。
