# 09 · 批次验收清单

操作者：组织者 + 仲裁员（真人双签）。每个批次（`BATCH-###`）进入 Gold 前必过。

## A. 合法性

- [ ] 本批每份简历均有**本人签署**的知情同意（consent-log 有哈希登记）；
- [ ] 签署时间早于导入时间（intake-log 对账无误）；
- [ ] 无撤回未处理项（withdrawal-log 无 open 状态）；
- [ ] 简历文件名/标注文件不含 PII（抽查 ≥5 个文件）。

## B. 数据质量

- [ ] 每份简历配对数符合规划（Scenario B：8 岗位/简历），不足项显式登记；
- [ ] 无机械复制凑数（重复 resume/job 组合逐一核对并隔离登记）；
- [ ] 每个查询组可判候选 ≥2（`min_group_size_for_ranking`），不足组剔除并登记；
- [ ] 文件哈希与 intake-log 一致（`check_artifact_integrity.py` 口径复核）。

## C. 标注质量

- [ ] 双人标注覆盖率 100%（A、B 均完成）；
- [ ] 分歧全部仲裁完毕（disagreements 清零或全部有 arbitration 记录）；
- [ ] 仲裁记录含理由与仲裁员编号（缺失项退回重做）；
- [ ] 抽查 ≥10% 一致项复核通过（双人同错率登记）；
- [ ] 标注员/仲裁员为真实人类本人（组织者当面确认，签字为证）。

## D. 对账与留痕

- [ ] `audit_real_data_status.py` 计数与 `08-daily-progress-template.md` 一致；
- [ ] 本清单双签：组织者 ______ 日期 ______ / 仲裁员 ______ 日期 ______；
- [ ] 批次验收结论（通过/退回）登记到批次报告。

## 不通过处理

任何一项不通过 → 该批次**不得**进入 Gold 冻结；退回整改后重新验收。
禁止「先冻结后补验收」。
