# 简历数据授权说明与收集模板（`phase4-3a-2-consent-v1`）

> 用途：本毕业设计《大学生就业岗位画像与简历智能匹配系统的设计与实现》的**人工 Gold 评估集建设**。
> 本模板是数据收集的知情同意文本与授权登记格式，配套
> [`phase4-3a-2-data-collection.md`](phase4-3a-2-data-collection.md) 与
> `src/job_matching/annotation/consent.py` 的字段校验（`CONSENT_FIELDS`）。

## 一、知情同意书模板（面向简历提供者本人）

### 1. 研究目的

我们正在进行毕业设计研究：构建"大学生就业岗位画像与简历智能匹配系统"，并需要一小批
真实中文简历，由人工评估"该简历与若干岗位是否匹配"，用于检验匹配算法的评估口径是否可靠。
本研究**不用于商业招聘、不用于向任何第三方提供您的简历、不用于训练对外发布的模型**。

### 2. 处理的数据类别

仅处理与求职匹配判断相关的信息：

- 教育背景（学校层次/学历/专业/毕业届别）；
- 求职意向（目标岗位、城市、薪资期望，可选）；
- 技能、项目/实习/工作经历描述。

**不收集**：身份证号码、家庭住址、婚姻状况、政治面貌、照片、真实姓名、手机号、
个人邮箱、微信/QQ 号等与匹配判断无关或可直接识别个人的信息。若简历原文中包含上述信息，
导入时会被脱敏掩码（`***`）后才会进入研究数据。

### 3. 使用范围与期限

- 仅用于本毕业设计约定的用途：人工标注人岗匹配相关性、计算标注一致性、冻结评估集、
  在该评估集上比较匹配算法；
- 数据仅保存在研究者本人设备的非公开目录（`data/private/`，不进入任何公开代码仓库）；
- 访问范围：研究者本人与（如参与）标注员；标注员只能看到去标识化的简历文本；
- 保存期限：毕业设计评审结束后 90 天内删除，或按您的要求提前删除。

### 4. 撤回与删除

- 您可随时联系研究者要求撤回授权并删除数据（提供下方撤回方式即可，无需说明理由）；
- 收到撤回请求后 7 天内完成删除：原文、脱敏副本、派生的标注记录一并删除，
  已冻结版本若包含该记录则作废并重新冻结；
- 撤回不影响撤回前基于授权的处理活动。

### 5. 风险与收益

- 风险：即使脱敏，仍存在极小的再识别风险；我们通过随机 `resume_id`、字段白名单、
  PII 扫描降低该风险；
- 您不会获得直接报酬；研究结论将在毕业论文中呈现，不包含任何可识别个人的内容。

## 二、授权登记记录（CSV，字段与 `consent.CONSENT_FIELDS` 严格一致）

存放位置：`data/private/consent/consent_records.csv`（**不入库**）。
`consent.py::validate_consent_record` 会逐条校验，缺失/非法直接拒绝导入。

| 字段 | 说明 | 示例 |
|---|---|---|
| `consent_id` | 授权记录唯一 ID | `consent_2026q4_0001` |
| `resume_id` | 关联的随机化简历 ID（`resume_<sha12>`，禁止真实姓名） | `resume_3fa9c2d10b7e` |
| `source_class` | `A_consented_individual` / `B_licensed_public` / `C_synthetic` | `A_consented_individual` |
| `subject_pseudo_id` | 随机化代号（字母开头，3–32 位，禁中文） | `subj_k7p2x9` |
| `consent_status` | `granted` / `licensed` / `withdrawn` / `denied` / `not_applicable` | `granted` |
| `purpose` | 使用目的（与知情同意书一致） | `毕业设计人工Gold评估集建设` |
| `data_categories` | 处理的数据类别 | `教育背景;求职意向;技能与经历` |
| `storage_note` | 保存方式 | `本地 data/private/ 非公开目录` |
| `access_scope` | 访问范围 | `研究者本人与标注员` |
| `withdrawal_method` | 撤回与删除方式（**必填**） | `邮件联系研究者，7日内删除` |
| `granted_at` | 授权时间（ISO 日期/时间） | `2026-10-29` |
| `license` | B 类必填：许可名称 | `cc-by-4.0` |
| `license_evidence` | B 类必填：许可证据（文件/链接/截图位置） | `data/private/consent/evidence/B001-license.png` |

规则摘要（`consent.py` 强制执行）：

1. A/B 类 `consent_status` 必须是 `granted`/`licensed`，否则禁止进入 Gold；
2. C 合成来源必须显式声明 `C_synthetic` 且 `consent_status=not_applicable`，
   冒充真实来源直接报错；
3. 同一 `resume_id` 多条授权记录直接报错（禁止静默覆盖）；
4. `subject_pseudo_id` 禁止中文与真实姓名形态。

## 三、B 类（公开数据集）准入检查清单

在把任何公开简历数据集加入研究前，逐项确认并把证据存入 `data/private/consent/evidence/`：

- [ ] 许可证明确允许**研究/学术**用途（记录 license 名称与版本）；
- [ ] 许可证据可核（数据集页面 LICENSE 文件、卡片 front-matter、发布者声明截图）；
- [ ] 数据集来源可追溯（发布者/仓库标识）；
- [ ] 同意范围覆盖"人工标注再评估"这一衍生使用；
- [ ] 未通过登录墙/反爬绕过等手段获取；
- [ ] 数据集本身不含（或已允许处理）个人信息风险的声明已阅读。

不满足任一项 → 进入隔离清单（`reports/phase4-3a-2/source-audit.json` 的
`quarantine_list`），**不得进入正式 Gold 池**。
