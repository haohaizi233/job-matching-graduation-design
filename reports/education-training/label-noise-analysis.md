# 第四阶段 4.2 · 伪标签噪声与标签冲突分析

- 生成时间：2026-10-28
- 机器可读结果：`reports/education-training/label-noise.json`（`analyze_learnability.py` 产出）
- 训练实验记录：`reports/education-training/runs/*.json`、`models/education/<model>/<run_id>/manifest.json`
- 标签来源约定：开发集（train 180,903 / validation 45,226）标签全部是 `pseudo_online`
  （旧线上系统输出，人工复核一致率仅 **45.92%（338/736）**，见 `reports/baselines/education-baselines.md`）；
  `gold_holdout` 736 行是 `human_gold`，只做一次性最终评估。

> 本报告所有"准确率"都是**对伪标签的拟合程度**，不是人工标注准确率。
> 第三阶段已用 gold 做过规则基线比较，本阶段 gold 不参与训练、阈值选择、清洗规则选择与模型选择。

## 1. 伪标签分布（train，180,903 行）

| 标签 token | 支持数 | 占比 |
|---|---|---|
| 本科 | 130,518 | 72.15% |
| 硕士 | 110,686 | 61.19% |
| 博士 | 98,606 | 54.51% |
| 大专 | 50,272 | 27.79% |
| 学历不明 | 2,442 | 1.35% |
| 学历不限 | 708 | 0.39% |

- 标签组合数：**13** 种；多标签行（≥2 个 token）占 **56.55%**。
- 最大组合：`["博士","硕士","本科"]` 58,271 行、`["博士","硕士","本科","大专"]` 25,824 行、
  `["本科"]` 39,401 行、`["大专"]` 23,245 行。
- 互斥规则检查通过：`学历不限` / `学历不明` 从未与具体学历或彼此共现（`exclusivity_check` 全 0）。
- 阈值类长尾极不均衡：`学历不限` 708 行 vs `本科` 130,518 行（1:184）。
- validation（45,226 行）分布与 train 基本同形（14 种组合，多标签 56.47%）。

人工金标准（736 行）的分布与伪标签明显不同：

| 对比项 | 伪标签（train） | 人工金标准 |
|---|---|---|
| 多标签比例 | 56.55% | **62.77%** |
| `["博士","硕士"]` | 6.2% | **32.3%** |
| `["博士","硕士","本科","大专"]` | 14.3% | 7.6% |
| `学历不限`+`学历不明` | 1.74% | 0.41% |

## 2. 同输入异标签冲突（不可辨识性）

| 指标 | 实测值 |
|---|---|
| 存在标签冲突的槽位表达 | **33 / 79** |
| 落在冲突槽位上的行 | **180,736（99.91%）** |
| 仅凭槽位可辨识的槽位 | 46/79（58.23%），但只覆盖 167 行 |

常见冲突模式（train）：

| 槽位 | 众数组合（占比） | 次常见组合（占比） | 冲突本质 |
|---|---|---|---|
| `本科` | `["博士","硕士","本科"]` 49.70% | `["本科"]` 42.1% | 「及以上」是否展开成多学历 |
| `大专` | `["大专"]` 50.07% | `["博士","硕士","本科","大专"]` 45.0% | 同上，方向相反 |
| `硕士` | `["硕士"]` 44.87% | `["博士","硕士"]` 41.2% | 同上 |
| （空槽位） | `["博士","硕士","本科"]` 48.66% | `["学历不明"]` 20.6% | 上游未抽取时的兜底惯例不一致 |
| `硕士研究生` | `["博士","硕士"]` 50.88% | `["硕士"]` 44.5% | 同上 |

**结论**：冲突不是随机噪声，而是**同一表达的两种系统性解释并存**（"学历门槛" vs "学历精确匹配"），
且伪标签系统对同一表达的解释不稳定（近似 50/50）。这部分歧义不携带在输入里，
任何模型都无法从槽位文本"学会"消解它（上限 = 每槽位众数，validation exact ≈ 0.5243）。

## 3. 标签共现频率（train）

| 组合 | 共现行数 | 解读 |
|---|---|---|
| 博士+硕士 | 95,284 | 「X及以上」展开的产物 |
| 硕士+本科 | 89,978 | 同上 |
| 博士+本科 | 84,135 | 同上 |
| 本科+大专 | 27,027 | 大专及以上类 |
| 硕士+大专 | 25,928 | 四级展开的伴随项 |
| 博士+学历不明 / 硕士+学历不限 等 | **0** | 终态 token 互斥，未被破坏 |

`博士+大专` 25,824 行全部来自 `["博士","硕士","本科","大专"]` 这一"四级全展开"组合——
说明共现结构由少数展开惯例决定，不是独立语义。

## 4. 确定性规则 vs 伪标签的系统性偏差

60,000 行抽样（`label-noise.json.rule_vs_pseudo_bias`；比较对象是伪标签，不是人工真值）：

| 标签 | 两者一致 | 伪标签正例 | 规则正例 | 伪标签有/规则无 | 规则有/伪标签无 |
|---|---|---|---|---|---|
| 博士 | 3,787 | 32,841 | 4,005 | **29,054** | 218 |
| 硕士 | 8,891 | 36,895 | 9,064 | **28,004** | 173 |
| 本科 | 32,442 | 43,256 | 32,927 | 10,814 | 485 |
| 大专 | 15,852 | 16,675 | 16,324 | 823 | 472 |
| 学历不明 | 806 | 806 | 4,056 | 0 | 3,250 |
| 学历不限 | 169 | 221 | 236 | 52 | 67 |

方向性结论（已被数据证实）：
1. 伪标签把「及以上」展开为**含博士/硕士的多学历组合**的频率远高于确定性规则
   （博士：32,841 vs 4,005，约 8 倍），这是最大的单一系统性偏差；
2. 确定性规则把空/无要求槽位判为 `学历不明` 的频率远高于伪标签（4,056 vs 806）；
3. 两者在 `大专` 上接近。该偏差解释了为什么"规则 vs 模型"对照中模型只是在
   拟合伪标签惯例，而 gold 上没有优势。

## 5. 样本权重与伪标签清洗实验（第二部分 2.2 / 2.3 要求）

三种训练设置 + 两种权重策略全部实际训练（同一 validation 阈值选择口径，
阈值逐标签按 validation F1 在 0.20–0.80 网格上选择，未使用 gold）：

| 训练设置 | 说明 | TF-IDF val exact / microF1 | CharCNN val exact / microF1 | gold exact / microF1（一次性参考） |
|---|---|---|---|---|
| 原始伪标签（`none`） | 180,903 行，按原始频次 | **0.5015 / 0.8017** | 0.4694 / 0.7970 | TF-IDF **0.5190 / 0.8021**；CharCNN 0.4755 / 0.7938 |
| 输入组平衡（`slot_balanced`） | 每个唯一表达总权重 = 1 | 0.5017 / 0.8017 | 0.4695 / 0.7971 | TF-IDF 0.5190 / 0.8021；CharCNN 0.4755 / 0.7938 |
| **冲突感知加权（`conflict_aware`）** | w = P(标签组合\|槽位) 众数占比（train 统计，均值归一） | 0.5017 / 0.8017 | 0.4701 / 0.7972 | TF-IDF 0.5190 / 0.8021；CharCNN 0.5122 / 0.8000* |
| **高置信度子集（`high_conf`）** | 见下表筛选 | 0.4988 / 0.8003 | 0.3515 / 0.7887 | 0.4823 / 0.7958 / 0.3478 / 0.7839 |

（CharCNN 另有 `val_loss` 早停变体，见 `experiment-comparison.md`；表中 `none` / `slot_balanced`
行为 `micro_f1_fixed05` 早停版本，`conflict_aware` / `high_conf` 为 `val_loss` 早停版本。
\* gold 0.5122 的改善来自**早停监控量从离散 micro-F1 换成 val_loss**（`val_loss` 变体均为 0.5122），
不是冲突权重本身的作用——冲突权重的对照（同为 val_loss 早停）显示其影响 < 0.1 个百分点。）

### 高置信度子集筛选记录（保留前后数量与原因）

定义（`dataset.high_confidence_subset`）：`label_status=='ok'` 且 槽位非空 且
P(标签组合|槽位) 众数占比 ≥ 0.90，**统计量只来自 train**；置信度来自训练集内部标签一致性，
与任何模型预测无关（不是"与当前模型一致"），gold_holdout 不参与定义。

| 项目 | 数量 |
|---|---|
| 筛选前 | 180,903 行 |
| 筛选后 | **6,324 行**（55 个唯一槽位） |
| 丢弃：空槽位 | 11,856 |
| 丢弃：`label_status != ok` | 0 |
| 丢弃：众数占比 < 0.90 | 162,723 |
| 保留行中非众数组合 | 420（槽位级筛选的必然残留） |

实验结论（真实数值）：
1. **冲突感知加权没有带来任何提升**（TF-IDF 三个权重策略 microF1 全部 0.8017）；
   说明性能瓶颈不是"高频表达主导"，而是伪标签本身的惯例冲突。
2. **高置信度子集反而显著变差**（CharCNN exact 0.47→0.35）：子集只含槽位内部一致的行，
   多样性坍缩到 55 个表达、且多标签展开惯例被众数过滤，模型学不到完整组合空间。
3. 所有噪声处理都没有在 gold 上产生稳定改善 → **伪标签清洗不能替代人工标注**。
4. TF-IDF（slot+job_title 上下文）在伪标签上提升（exact 0.5015→0.5347）但在 gold 上下降
   （0.5190→0.4851），是"拟合伪标签系统偏差"的直接证据（见 `error-analysis.md`）。

## 6. 标签冲突的推理期处理

`EducationNormalizer` 在阈值化后执行确定性冲突消解（`predictor.py::_to_labels`）：
`学历不限/学历不明` 与具体学历互斥时保留平均分数更高的一侧；两个终态 token 同现时取分数更高者。
该规则依据 `configs/education_labels.yaml` 的互斥终态定义，推理阶段不读取任何监督字段
（`model-verification.json.predictor_source_check` 通过）。

## 7. 限制声明

1. 开发集指标度量的是对伪标签的拟合能力；伪标签与人工结论一致率仅 45.92%，
   因此**不能**把 validation 指标解释为真实规范化准确率。
2. gold 736 行已在第三阶段用于规则基线比较，本阶段只做一次性最终评估，
   不是全新盲测集；若需真正的泛化结论，需要新增人工标注（采样方案见
   `phase4-2-acceptance.md` 的后续建议）。
3. 本阶段未训练"伪标签 + 人工混合"模型（gold 太小且已被评估消耗），明确留作后续工作。
