# 大学生就业岗位画像与简历智能匹配系统 — 简历管理页面复刻

## 文件说明

- `index.html`：HTML/CSS/JavaScript 源码，引用 `assets/` 中的独立素材。保留目录结构，在浏览器打开即可查看。
- `standalone.html`：**完全离线的单文件**，所有图片内嵌为 data URI，浏览器双击打开。
- `assets/`：顶部毕业帽、头像、校园横幅右侧建筑与纸飞机、左侧云层、侧栏学生插画；界面上的卡片、表格、控件和状态图标均以 HTML/CSS/SVG 实现。
- `preview-desktop.png`、`preview-mobile.png`：使用 Chromium 实际渲染的页面截图。

## 还原内容

以用户提供的 1448×1086 截图为基准，复刻顶栏、八项侧边导航、校园横幅、四项简历统计、上传区域、四步解析流程、三行简历数据及解析失败提示、常见问题列表。

## 交互（前端演示）

- 选择或拖拽 PDF/DOCX/TXT，检验大小不超过 10 MB、拒绝空文件；模拟解析状态变化并刷新列表统计。
- 查看简历详情、尝试下载、重新解析、删除演示记录。
- 常见问题展开/折叠；通知和头像菜单。

**注意：** 这些操作均为前端本地演示，上传/解析不会发往服务器，历史演示简历不存在真实可下载文件。要实现真实 OCR、简历解析和个人画像，需要对接后端 FastAPI 服务与文件存储。校园插画作为切取/重组的装饰素材，字体细节和图片会与参考截图存在少量偏差；并非将整张截图直接用作背景。
