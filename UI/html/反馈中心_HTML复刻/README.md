# 大学生就业岗位画像与简历智能匹配系统 — 反馈中心高保真 HTML

## 交付

- `standalone.html`：完全离线单文件版，HTML/CSS/JavaScript/PNG 已内嵌，双击即可打开。
- `index.html` + `assets/`：工程化分离素材版，可直接打开 `index.html`。
- `preview-desktop.png`：按参考图 1672 × 941 的浏览器截图。
- `preview-mobile.png`：390px 手机端完整截图。
- `test_page.py`：Chromium Playwright 自动化交互校验，包含趋势切换、表格筛选、详情切换和备注编辑。
- `test-results.txt`：实际运行输出。

## 功能与口径

此交付为**前端高保真复刻与交互演示**，以提供的截图为视觉依据，未集成数据库、账户认证、岗位检索或模型服务。指标（98条、82%、92% 等）均为截图中的示例值。6 条行数据用于演示表格交互，不应误认为生产环境真实记录。

趋势区支持近7天 / 近30天 / 近3个月；反馈记录支持状态标签筛选、全状态下拉框、公司岗位搜索；选中记录时更新右侧详情；可更改感兴趣/不感兴趣/已投递/已面试状态；支持备注编辑、收藏、撤回反馈及模拟再次推荐。

全部前端表单行为只在当前浏览器会话内生效，不会向任何服务器提交数据。刷新页面将复位演示数据。

## 注意

- 参考截图是 1672×941 的桌面界面，复刻按照该比例校准，但由于字体渲染、细微渐变和部分图片素材裁剪不同，不是严格的逐像素拷贝。
- 页面主体采用真实 HTML/CSS/SVG，不使用整页截图作为背景；仅校园横幅、品牌头像与插画等装饰元素采用独立图片。
- 单文件与分离素材版功能相同。
