# 岗位探索｜大学生就业岗位画像与简历智能匹配系统

基于用户提供的 1448 × 1086 工作台「岗位探索」截图制作的独立 HTML/CSS/JavaScript 高保真前端复刻项目。

## 打开方式

- **单文件版**：直接用 Chrome / Edge 双击打开 `standalone.html`，无需联网、无需启动服务器。
- **源码版**：将 `index.html`、`styles.css`、`app.js` 和 `assets/` 保持在同一目录，在浏览器中打开 `index.html`。也可以在本目录运行 `python -m http.server 8080` 并访问 `http://127.0.0.1:8080/`。
- `preview-desktop.png` 为 1448 × 1086 的真实浏览器截图；`preview-mobile.png` 为 390px 视口的实际全页截图。

## 结构及功能

- 顶部导航栏、左侧导航栏、校园横幅、筛选面板、已选筛选标签、排序栏、岗位列表和响应式卡片视图。
- 关键词、城市、岗位类别、学历、技能标签、薪资区间的本地筛选。
- 综合排序、最新发布、薪资升降序、匹配度排序；列表与卡片模式切换。
- 岗位详情弹窗、加入/移出匹配、加载更多、重置筛选、顶部搜索、消息与账户菜单。
- 所有交互使用浏览器内存演示数据实现，不会发送网络请求或写入后端。

## 还原原则与限制

- 页面骨架、表单、文字、卡片、按钮、排序及交互均由真实 HTML/CSS/JS 绘制；**没有将整张截图作为页面背景**。
- 校园横幅右侧图像与公司标识局部使用截图提供的素材重新裁切；左侧横幅文字用 HTML 实现。侧栏插画使用相同视觉系列的独立素材。
- 用户截图显示“共 1,286 个岗位”和“已选条件 北京、本科、产品经理”，但所展示的示例岗位包含其他城市；为了保持截图视觉，首次载入保留这一展示状态。实际点击“搜索岗位”后才按当前表单过滤；初始 1,286 是截图演示数，**不是从后端查询的数据量**。
- 源截图可辨识的前五个岗位已编入示例数据；另补三个**虚构的界面演示样例**，仅用于验证加载更多和筛选。它们不是实时在招岗位。
- 页面是独立的可交互前端复刻，**没有接入 FastAPI 或数据库**。像素差异主要来自字体系统、图标微细节以及图像压缩。

## 浏览器验证

使用 Playwright + Chromium 1448 × 1086 与 390 × 844 视口检查。已验证：主模块位置、关键词搜索、重置、排序/视图切换、详情弹窗、加入匹配、加载更多；无 JavaScript 异常，移动端无横向溢出。

可执行 `python qa.py` 在具备 Playwright/Chromium 的环境重新验证；`python build_standalone.py` 可从源码更新单文件。
