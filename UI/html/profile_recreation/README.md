# 大学生就业系统 — 我的职业画像页面（HTML 高保真复刻）

参考用户提供的 1448 × 1086 UI 截图制作。内容以原截图中的演示数据为准；这些数据不是模型实际计算结果。

## 使用方式

- **单文件：** 直接用浏览器打开 `standalone.html`，CSS、JS 和图片均已内嵌，无网络依赖。
- **源码版：** 打开 `index.html`（引用同目录的 `styles.css`、`app.js`、`assets/`）。
- **截图：** `preview-desktop.png` 为 Chromium 在 1448 × 1086 视口的实际渲染；`preview-mobile.png` 为 390 × 844 视口的完整长图。

## 页面结构

1. 顶部导航 + 左侧菜单 + 校园欢迎横幅
2. 个人信息 + SVG 五维雷达图 + 画像版本信息
3. 求职意向 + 可编辑核心技能标签
4. 学历背景 + 项目经历
5. 实习经历 + 来源占比（42% / 38% / 20%）
6. 底部画像编辑区域

## 前端交互

- 查看消息、用户菜单，搜索关键词提示
- 修改昵称、修改头像（仅内存）、编辑期望岗位
- 新增/删除技能标签、编辑学历弹窗
- 查看版本历史与版本对比、项目和实习详情
- 自我介绍、职业目标字数计数与确认/取消
- 使用 CSS Grid、Flexbox 和响应式断点适配不同屏宽

## 注意

- 页面为独立 HTML/CSS/JS 演示，没有接入 FastAPI、PostgreSQL 或登录态接口，刷新后交互数据恢复。
- 为还原参考图，部分插画与头像素材从用户提供的截图及本会话已有的插画素材中提取；主体内容是结构化 HTML/CSS/SVG，并非整屏截图铺底。
- 视觉布局按 1448 px 视口对齐，字体渲染、素材清晰度与浏览器环境可能造成细小差别；“一比一”属于高保真视觉目标，不承诺像素级完全一致。
