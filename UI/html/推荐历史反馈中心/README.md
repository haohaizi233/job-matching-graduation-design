# 大学生就业岗位画像与简历智能匹配系统 — 推荐历史 / 反馈中心

本目录根据用户提供的 1448×1086 截图复刻。使用真实 HTML、CSS、SVG 与 JavaScript，而不是将整张页面截图作为背景。

## 文件

- `standalone.html`: 单文件版本，样式、脚本、页面装饰素材全部内嵌；无需服务器或联网，双击打开即可查看。
- `index.html`: 开发版本，引用 `assets/` 内独立 PNG 文件；双击可打开，也可通过静态 HTTP 服务预览。
- `assets/`: 校园横幅、侧边栏插画、头像与企业标识等装饰素材。
- `preview-desktop.png`: Chromium 1448×1086 桌面实测截图。
- `preview-mobile.png`: Chromium 移动端实测截图。
- `qa_check.py`: Playwright 端到端页面检查脚本；Linux 上使用 `/usr/bin/chromium`，Windows 可改为本机浏览器。

## 功能

- 推荐历史记录：选择历史、过滤已完成/已过期、切换页码。
- 推荐结果：随历史选择更新标题、画像版本、推荐模式和演示统计值。
- 反馈中心：感兴趣、不感兴趣、已投递、获得面试、不相关；支持撤销当前状态。
- 筛选：反馈状态、所属行业、关键词。
- 备注：可编辑并保存于当前页面运行时内存（刷新后恢复演示数据）。
- 勾选岗位、重新匹配演示弹窗、消息通知、账户菜单。
- 响应式桌面与移动端适配。

## 重要说明

- 页面内历史次数、岗位推荐、评分、反馈数据均为**截图复刻所需的演示数据**，不是系统实时统计或真实模型结果。
- `重新运行匹配` 仅执行演示动作，不会调用模型 API，也不会生成真实推荐记录。
- 本页面不连接 FastAPI、数据库或登录系统，也不声称保存了反馈到服务器。
- 企业标识和装饰图使用现有视觉参考素材，局部文字渲染与渐变和原图可能存在差异；并非像素级完美一致。
