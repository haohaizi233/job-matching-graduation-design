# 大学生就业岗位画像与简历智能匹配系统｜个人设置页复刻

依据用户提供的 1672 × 941 页面截图进行高保真前端复刻。

## 打开方式

- **standalone.html**：已内嵌所有图片、CSS 和 JS，直接双击打开即可离线查看。
- **index.html**：可维护的源码入口，保留相对路径 `assets/`；下载整个目录后直接打开，或运行 `python -m http.server 8000`，访问 `http://localhost:8000`。

## 页面模块

- 顶部导航及侧栏（选中态为「个人设置」），校园横幅与左下角插画。
- 个人资料、登录设备、账号安全日志。
- 基本信息、通知偏好、简历解析设置、主题与显示设置。
- 密码与安全、隐私与数据权限、推荐偏好和操作区域。

## 演示交互

- 昵称编辑、学校专业信息输入、入学毕业年份和所在地区选择。
- 通知开关、隐私开关、单选配置及推荐标签的删除／添加。
- 设备下线确认、密码／手机／邮箱／二次验证弹窗。
- “保存设置”通过 `localStorage` 保存在当前浏览器，恢复默认清除存储；在浏览器限制本地存储时会给出提示。
- 消息通知、账户菜单、退出登录演示。

## 边界与说明

这是高保真的**前端演示页面**，数据为参考图示例数据，不调用真实账号、密码、设备管理或推荐服务。密码修改、二次验证、注销等动作仅演示前端验证与交互，必须接入真实服务后才能生效。

校园与头像、侧边插画来自用户提供的界面截图及此前该项目已使用的插画素材。除装饰性图像之外，卡片、图标、表单、列表、开关均为 HTML / CSS / SVG。

页面默认按 **1672 × 941** 像素校准，同时提供窄屏响应式布局。
