# 智能匹配页面 · 高保真 HTML 复刻

参考尺寸：**1448 × 1086**。本项目复刻提供的“智能匹配”页面截图（工作台导航体系）。

## 文件

- `standalone.html`：**单文件离线版本**，含 CSS、JavaScript 和所有 PNG 内嵌图片。直接用 Chrome/Edge 打开即可。
- `index.html`、`styles.css`、`app.js`：可维护的分文件源码。在此目录内打开 index.html 或使用本地静态服务器。
- `assets/`：从同系列原设计资源中提取的品牌标识、校园横幅、侧边栏插画、头像、部分企业图标。
- `preview-desktop.png`：Chromium 实际渲染的 1448×1086 桌面截图。
- `preview-mobile.png`：390px 移动端视口截图。
- `preview-filtered.png`：切换 Top K 后的交互截图。
- `test_ui.py`：本地验证脚本，需要安装 Python playwright 和 Chromium。
- `build_standalone.py`：重新生成单文件页面的构建脚本。

## 实现模块

- 固定顶部导航、侧边栏、校园横幅。
- 匹配设置：画像版本、综合排序/高匹配优先/高潜力优先、Top K、城市、岗位类别、开始匹配。
- 匹配结果：排名徽章、岗位与公司信息、技能标签、92%/88% 等匹配度圆环、收藏、查看详情、四维匹配原因、待补充技能。
- 右侧：匹配概览、结果分布环形图、TOP5 岗位类别、重要提示。
- 交互：筛选、排名方式切换、收藏/取消收藏、岗位详情弹窗、参数重置、Top K 更新、通知菜单、演示搜索。
- 响应式：在 390px 移动端不会产生横向页面溢出。

## 质量检查

- 桌面版检查关键定位：横幅 `(212, 75)`、匹配设置 `(212, 220)`、左侧结果 `(212, 385)`、首卡 `(222, 428)`，右侧概览 `(1029, 385)`、分布 `(1029, 625)`、提示 `(1029, 954)`。
- Chromium 初始加载：20 个岗位演示卡片，图片资源加载正常，0 个 JS 异常。
- 测试了收藏、岗位详情、模式切换、城市和类别筛选、参数重置、Top K=5、开始匹配。

## 重要说明

- 这是**UI 还原与交互演示**，20 条演示岗位数据及匹配分为界面示例，并非实际模型输出或招聘真实性能。
- **未接入** FastAPI、PostgreSQL、用户认证、异步任务以及模型服务。点击“开始匹配”仅在前端切换演示数据。
- 环形图与类别分布采用截图示例数据，不应当被解释为通过后端计算的真实统计结论。
- 字体、部分企业标识和插画边缘可能与原设计有细微像素差异；主体均为真实 HTML/CSS/SVG，不是整页截图贴图。
