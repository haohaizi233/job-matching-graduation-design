# 大学生就业岗位画像与简历智能匹配系统 · 岗位详情页 HTML 复刻

## 文件说明

- `standalone.html`：单文件离线版（HTML/CSS/JS/图片全部内嵌），直接使用浏览器打开。
- `index.html`：模块化 HTML，依赖同目录的 `styles.css`、`app.js` 和 `assets/`。
- `styles.css`：样式系统，桌面 1448×1086 截图定位优化，包含 1180px、800px、620px 响应式断点。
- `app.js`：标签切换、收藏切换、提示弹窗、通知及用户菜单等演示交互。
- `preview-desktop.png`：通过 Chromium 在 1448×1086 视口实际渲染出的截图。
- `preview-mobile.png`：通过 Chromium 在 390px 宽度实际渲染出的页面截图。
- `qa.py`：本地验证脚本，使用 Playwright 浏览器渲染 standalone 内容并检查交互。

## 复刻范围

1. 顶部品牌、全局搜索、消息和账户菜单；侧边八项导航及底部插画。
2. 面包屑、阿里巴巴后端开发岗位卡、薪资/工作地点/校招/发布时间/技能标签。
3. 岗位详情、公司介绍、原始 JD、结构化画像四个标签（默认岗位详情）。
4. 岗位职责、任职要求、技能要求、公司介绍。
5. 82% 匹配度预览、6/8 技能匹配、其他条件匹配与行动建议。
6. 自适应布局、收藏岗位、智能匹配说明弹窗和导航提示。

## 使用

- 无依赖：双击 `standalone.html`，离线打开。
- 模块化开发：`python -m http.server 8000`，浏览器访问 `http://localhost:8000`。

## 注意

这是根据截图制作的独立前端演示，岗位文本、82% 匹配度和 6/8 技能均为截图中的示例数据，并非服务端计算结果，更不是录用概率。没有接入 FastAPI 后端、数据库或真实投递/授权流程。小型公司建筑图、公司 logo 和页面装饰素材提取自用户提供的页面截图；界面其余部分为 HTML、CSS 和 SVG 元素。目标是高保真接近原图而非每像素完全相同。
